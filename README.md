# Timing-is-Everything
Scripts used in the BSc Hons thesis Timing is Everything: Circadian regulation and the heading response in temperate grasses. \
\
Batch scripts for RNAseq data processing: BAM, featurecounts, Genome download, QC \
\
R code for processing and initial RNA-seq exploration: count processing.R, DE per timepoint.R, indiv.genes.R, PCAandvolcano.R \
\
R code for candidate gene screening: KEGGandvenn.R, GO.R, intersection.R, light.clustering.R, stability.R, candidates.final.R, GI testing.R \
